
# 🏥 Hospital Patient Record System (SQL Project)

## 📌 Overview
This project demonstrates a relational SQL database designed to manage hospital operations, including patient details, doctor assignments, appointments, and billing.  
It helps analyze performance, revenue, and efficiency using SQL queries and relationships between multiple tables.

## 📂 Database Tables
1. **Patients** – Stores patient personal details.
2. **Doctors** – Contains doctor profiles and specializations.
3. **Appointments** – Tracks patient appointments and diagnoses.
4. **Billing** – Records treatment costs, medicine charges, and payment status.

## 💡 SQL Concepts Used
- Joins (INNER, LEFT, RIGHT)
- Aggregate Functions (SUM, AVG, COUNT)
- CASE Statements
- CTEs and Views
- Data Normalization and Constraints

## 📊 Example Insights
- Total revenue generated by hospital.
- Most frequently visited doctor.
- List of patients with pending payments.
- Monthly revenue trends.
- Doctor-wise average treatment cost.

## 🧠 Project Highlights
- Designed and normalized 4 relational tables.
- Wrote 10+ analytical queries to generate insights.
- Improved data consistency and accessibility for reporting.
